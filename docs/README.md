# Integrações Customizadas — Documentação (PT-BR)

## Visão geral

Este app adiciona ao ERPNext/Frappe módulos de integrações customizadas, incluindo:

- **Integracoes Customizadas** e **Provas** (e outros módulos mantidos neste app)
- **Contrato de Trabalho** (DocType, alertas de vencimento, etc.)

## Contencioso / Processos Judiciais

O módulo de **Contencioso / Processos Judiciais** (Processo Judicial, CJ Parte, CJ Prazo, DataJud, etc.) foi movido para o app **Jurídico** (módulo **Processo**). Para documentação e uso, consulte o app `juridico` em `apps/juridico/`.
