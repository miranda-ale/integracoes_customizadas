# Plano de Testes — Contencioso

O plano de testes do módulo de **Contencioso / Processos Judiciais** (Processo Judicial, prazos, permissões, sigilo, DataJud) está no app **Jurídico** (módulo **Processo**).

Para rodar os testes do módulo processo/jurídico:

```bash
bench run-tests juridico.processo.integracoes.tests.test_datajud
```

Consulte: `apps/juridico/`.
