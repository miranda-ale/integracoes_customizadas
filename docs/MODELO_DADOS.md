# Modelo de Dados — Contencioso / Processos Judiciais

O modelo de dados do módulo de **Contencioso / Processos Judiciais** (Processo Judicial, CJ Parte, CJ Evento, CJ Prazo, etc.) está implementado e documentado no app **Jurídico** (módulo **Processo**).

Consulte: `apps/juridico/` (DocTypes em `juridico/processo/doctype/`).
